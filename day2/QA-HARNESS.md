## 2. Required Selenium cases (§6.2.3)
| Case | Steps | Assertions |
|---|---|---|
| T1 QR + zero friction | GET `{BASE_WEB}/q/m1-live` | `current_url` ends with `/web/matches/match-m1/live`; `guest-video-player` + `live-score-banner` visible ≤ 3 s; `progressive-auth-modal` not displayed |
| T2 guest write block | fresh session; type into `chat-input-field`; click `chat-send-btn` | message text not in `chat-message-list`; modal displayed ≤ 2 s |
| T3 cart + score sync | click `add-to-guest-cart-btn` → `guest-cart-count` == "1"; POST `/audit/v1/events` score for match-m1 (from the test process) | banner text changes to the new score ≤ 500 ms (poll every 25 ms with JS `MutationObserver` timestamp) |
Isolation: each test resets? **No** — `/audit/v1/reset` once per session (session fixture, xdist `worker_id=="gw0"` lock file),
tests use fresh browser profiles and read the current score before posting the event.

## 3. Appium (§6.3)
- `scripts/appium-up.sh`: `npx -y appium@2.11.5 driver install uiautomator2@3.8.0 || true; npx appium@2.11.5 --port 4723 --relaxed-security`.
- Deep-link test uses `driver.execute_script('mobile: deepLink', {url, package})` **and** the spec's `adb shell am start -W …`
  (subprocess) and asserts `current_activity` + `testID` `match-live-screen` / `costream-screen` within 2 s.
- No device → tests `skip` with reason "no device"; `appium-report.xml` still produced (honest, never faked as pass).

## 5. NFR-1 probe (ours, mirrors the grader)

## 6. GitHub Actions `.github/workflows/autograde.yml`
```yaml
on: { push: { branches: [main, master] }, workflow_dispatch: {} }
jobs:
  autograde:
    runs-on: ubuntu-latest
    timeout-minutes: 30
    env: { DAY1_SALT: ci-salt-day1, DAY2_SALT: CI0123456789abcd }
    steps:
      - checkout (fetch-depth: 0)            # ancestry check needs history
      - ancestry: if [ -n "$DAY1_BASE_SHA" ]; git merge-base --is-ancestor $DAY1_BASE_SHA HEAD   (repo variable)
      - docker compose up -d --build; scripts/wait-for-health.sh http://localhost:8080/health 120
      - grid: curl 4444/status → jq '.value.ready == true and (.value.nodes|length) >= 3'
      - unit: cd backend && node --test (P1 + P2) ; ./run_tests.sh → COVERAGE.json + COVERAGE_DAY2.json
      - api:  pytest tests/api -m "not destructive" --junitxml=tests/reports/api-report.xml
      - selenium: pytest -n 3 tests/selenium --junitxml=tests/reports/selenium-report.xml
      - k6: grafana/k6 docker (network host) → tests/reports/k6-summary.json
      - upload-artifact tests/reports ; on failure: docker compose logs
```
The existing `ci.yml` stays (P1 guards). Static guard additions: fail if `DAY2_SALT` value-like literal appears, if any
`data-testid` from FRONTEND §2.2 is missing in `backend/src/web/live.html`.
